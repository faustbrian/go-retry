package retry // import "github.com/faustbrian/go-retry/v3"

Package retry executes explicitly classified operations under bounded retry
policies. Start with a constructed Policy and Do, and declare each attempt
outcome explicitly. The executor never decides idempotency or undoes side
effects. Attempt limits are mandatory; duration budgets and shared resilience
admission are explicit opt-ins.

Policies borrow collaborators and captured state. Calls are synchronous,
may overlap or reenter and are not forcibly preempted. Built-in strategies
have immutable state; consumers synchronize custom collaborators and RNGs.
There are no package workers or shutdown lifecycle. HTTP, PostgreSQL, logging
and telemetry adapters own their target-specific contracts. The module includes
their external dependencies, while the core imports resilience. No retry-owned
transport, database pool or telemetry exporter is created.

CONSTANTS

    MaxHistoryEntries is the largest failure history retained by a policy.

const MaxTerminalErrorBytes = 66
    MaxTerminalErrorBytes bounds human-readable errors returned by Do, not panic
    payloads, retained causes or value formatting.

TYPES

type Attempt struct {
	// Attempt is the one-based physical callback count.
	Attempt uint
	// Elapsed is nonnegative clock-sampled time since execution began.
	Elapsed time.Duration
	// Delay is the selected next pause, even if a budget rejects it before sleep.
	Delay time.Duration
	// Classification is the accepted result, or zero for unclassified outcomes.
	Classification Classification
	// Err retains a classified operation error, or nil for unclassified outcomes.
	// Retained errors are not copied or safe log text.
	Err error
}
    Attempt records an unsuccessful dispatch, not a successful operation value.
    Classified failures retain the original error object; unknown/invalid
    outcomes retain no error and have zero Classification and Delay.

type AttemptResult[T any] struct {
	// Value is returned to the caller only with OutcomeKnown and nil error.
	Value T
	// Outcome must be OutcomeKnown, or OutcomeUnknown with a non-nil error.
	// OutcomeNotDispatched is invalid after invocation; errors alone do not
	// establish the dispatch outcome.
	Outcome Outcome
}
    AttemptResult declares the value and side-effect outcome of one attempt.

type Backoff interface {
	// Delay receives the failed operation ordinal (1 before the first retry)
	// and previous fully selected delay. It must bound its synchronous work;
	// returned negative durations are clamped by Policy. Calls may overlap.
	Delay(attempt uint, previous time.Duration, random Random) time.Duration
}
    Backoff computes the delay before retry attempt. Attempt starts at one for
    the first retry. Previous is the previously selected delay and is used only
    by state-dependent strategies such as decorrelated jitter.

func Constant(delay time.Duration) Backoff
    Constant returns the same non-negative delay for every attempt.

func DecorrelatedJitter(base time.Duration) Backoff
    DecorrelatedJitter chooses uniformly between base and three times the
    previous delay. The first retry uses base as its previous delay.

func EqualJitter(backoff Backoff) Backoff
    EqualJitter retains half of the wrapped delay and uniformly jitters the
    remainder. Nil backoff yields zero; nil randomness selects the lower bound.
    The wrapped implementation and random source are borrowed.

func Exponential(initial time.Duration, multiplier uint64) Backoff
    Exponential returns initial*multiplier^(attempt-1) with saturation.

func ExponentialJitter(initial time.Duration, multiplier uint64, factor float64) Backoff
    ExponentialJitter applies centered proportional jitter to exponential
    backoff. Finite Factor is clamped to [0, 1]; NaN is not validated and has no
    promised jitter range.

func Fibonacci(unit time.Duration) Backoff
    Fibonacci returns unit multiplied by the attempt-th Fibonacci number,
    where the first two retry delays both equal unit.

func FullJitter(backoff Backoff) Backoff
    FullJitter borrows backoff and chooses between zero and its nonnegative
    delay. Nil backoff yields zero; nil randomness selects zero after the
    wrapped delay is computed. A typed-nil implementation can still panic.
    Randomness must meet Random's uniformity contract.

func Linear(initial, increment time.Duration) Backoff
    Linear returns initial + (attempt-1)*increment, using saturating arithmetic.

func Polynomial(base, coefficient time.Duration, power uint) Backoff
    Polynomial returns base + coefficient*attempt^power with saturation.

type Classification uint8
    Classification is an explicit decision about one operation failure.

const (
	// ClassificationPermanent stops execution and preserves the operation error.
	ClassificationPermanent Classification = iota + 1
	// ClassificationRetryable permits another bounded attempt.
	ClassificationRetryable
)
type Classifier interface {
	// Classify receives the caller context and exact operation error. Return
	// ClassificationPermanent or ClassificationRetryable; other results stop
	// execution as classifier failures.
	Classify(context.Context, error) (Classification, error)
}
    Classifier classifies an operation failure. Returning an error means the
    classifier itself failed and execution stops. It must be bounded and safe
    for overlapping calls when shared. Classification never establishes replay
    safety; error traversal and retained causes remain caller trust boundaries.

func RetryableClassifier() Classifier
    RetryableClassifier returns a classifier that retries RetryableError
    values and treats every other error as permanent. It does not inspect
    PermanentError first: a nested RetryableError still makes the chain
    retryable. Context and outcome precedence belong to the executor, not this
    classifier.

type ClassifyFunc func(context.Context, error) (Classification, error)
    ClassifyFunc borrows a function as Classifier. Direct calls propagate
    panics; Do contains classifier panics with bounded terminal errors. A nil
    function is rejected as a required policy collaborator.

func (function ClassifyFunc) Classify(ctx context.Context, err error) (Classification, error)
    Classify invokes the adapted function.

type Clock interface {
	// Now returns the time used for budgets, history and delay hints.
	Now() time.Time
}
    Clock supplies policy time for elapsed accounting. Implementations must be
    safe for concurrent calls when the policy is shared and should provide a
    consistent time progression. Backward elapsed differences are clamped to
    zero. Implement TimeoutClock as well to control per-attempt deadlines.

type Config struct {
	// Backoff is required; its implementation is borrowed and called synchronously.
	Backoff Backoff
	// MaxAttempts is required and includes the original call; one means no retries.
	MaxAttempts uint
	// MaxElapsed is a sampled elapsed budget; zero disables it. Attempt contexts
	// use the remaining budget, but collaborators and sleeps are not forcibly preempted.
	MaxElapsed time.Duration
	// AttemptTimeout adds a cooperative deadline per operation; zero disables it
	// unless MaxElapsed supplies a remaining deadline.
	AttemptTimeout time.Duration
	// MinDelay floors selected retry delays, including available server hints.
	MinDelay time.Duration
	// MaxDelay caps selected delays and hints; zero disables the cap.
	MaxDelay time.Duration
	// MaxSleep caps accumulated successful sleep requests; zero disables it.
	// It does not measure actual sleeper wall time.
	MaxSleep time.Duration
	// StopBeforeDeadline stops instead of sleeping when the selected delay
	// would reach the caller context deadline, measured on Clock, so callers
	// holding scarce resources get the last failure at once rather than after
	// cancellation. A custom Clock must agree with the context deadline.
	StopBeforeDeadline bool
	// Clock is required and borrowed for elapsed accounting and optional deadlines.
	Clock Clock
	// Sleeper is required and borrowed; it receives the caller context, not
	// an attempt or MaxElapsed-derived context.
	Sleeper Sleeper
	// Random is optional and borrowed; nil selects deterministic jitter lower bounds.
	Random Random
	// Classifier is required and receives the original failure and caller context,
	// not the attempt context.
	Classifier Classifier
	// Observer is optional, synchronous and borrowed. Engine calls contain panics,
	// not blocking or arbitrary side effects.
	Observer Observer
	// HistoryLimit retains the most recent recorded failures up to MaxHistoryEntries.
	// Zero disables history; error objects are borrowed and not byte-bounded.
	HistoryLimit uint
	// UseResilienceBudget consumes the shared work-amplification scope attached
	// to the execution context. Existing standalone behavior is unchanged when false.
	UseResilienceBudget bool
}
    Config contains all dependencies and bounds for a Policy. MaxAttempts is
    mandatory so no policy can retry forever.

type DelayHint interface {

type ExecutionResult[T any] struct {
	// Value is set only for known success and otherwise is the zero T.
	Value T
	// Retry contains bounded metadata; retained error objects may be private.
	Retry Result
	// Outcome identifies dispatch knowledge, never permission to repeat side effects.
	Outcome Outcome
}
    ExecutionResult contains a value only for known success, bounded retry
    metadata, and the operation dispatch outcome.

func Do[T any](ctx context.Context, policy *Policy, operation Operation[T]) (ExecutionResult[T], error)
    Do executes operation under policy without retrying an unknown outcome and
    returns only bounded human-readable terminal errors. Nil/typed-nil ctx,
    nil policy or operation returns ErrInvalidPolicy. Use a constructed policy.
    Known success wins caller/attempt deadline races. Known failures retain
    timeout and classification precedence before later caller-cancellation
    checks. Unknown or invalid outcomes terminate without classification,
    delay selection or retry. Human text is safe by category, not arbitrary
    cause/history traversal. Collaborators may block or overlap; deadlines
    are cooperative. Acquired permits and attempt contexts are released,
    not side effects rolled back. Permit completion errors are ignored and
    completion/operation panics propagate.

type Observation struct {
	// Attempt is the completed callback ordinal, or zero before first dispatch.
	Attempt uint
	// Elapsed is the sampled elapsed time at this notification.
	Elapsed time.Duration
	// NextDelay is a selected pause, not a completed sleep.
	NextDelay time.Duration
	// Classification is zero when no failure was classified.
	Classification Classification
	// Reason is empty for a selected retry pause and populated for terminal events.
	Reason Reason
}
    Observation describes a reached notification site; it is not proof of a
    physical dispatch. Early work-budget refusal can report attempt zero, and
    several cancellation, budget and collaborator-failure paths emit no event.

type ObserveFunc func(Observation)
    ObserveFunc borrows a callback as Observer. A nil function panics on direct
    invocation; policy construction rejects explicitly typed-nil collaborators.

func (function ObserveFunc) Observe(observation Observation)
    Observe invokes the adapted function.

type Observer interface {
	// Observe consumes a copied notification with no operation value or error.
	Observe(Observation)
}
    Observer receives scalar lifecycle metadata synchronously. Calls may overlap
    or reenter execution; no package lock is held. Engine calls contain panics,
    but direct calls propagate them. Blocking observers block the retry caller.
    Notifications are not a complete audit of all attempt or terminal paths.

type Operation[T any] func(context.Context) (AttemptResult[T], error)
    Operation executes one attempt and declares whether its outcome is known.
    It must never label an ambiguous side effect as known or return
    OutcomeNotDispatched after invocation. Captured state is borrowed; calls
    execute synchronously and operation panics propagate, with owned cleanup.

type Outcome uint8

type Policy struct {
	// Has unexported fields.
}
    Policy copies configuration but borrows collaborators and captured state.
    Construct it with NewPolicy; the zero Policy is unusable. Concurrent
    executions are safe only when all shared collaborators are safe; retry owns
    no worker, shutdown lifecycle, callback lock or forced preemption.

    NewPolicy validates finite attempt count, required dependencies and
    consistent nonnegative duration/history limits. Scalars are copied;
    dependencies are borrowed. Explicitly typed-nil optional Random/Observer

type Random interface {
	// Int64n must return a uniform sample for positive upper. It may be called
	// concurrently by a shared policy; it is not a cryptographic interface.
	Int64n(upper int64) int64
}
    Random is an injected, concurrency-safe source of uniform integers in [0,
    upper). Implementations must return zero when upper is non-positive.

func ParseRetryAfter(value string, now time.Time) (time.Duration, bool)

package retryadapter // import "github.com/faustbrian/go-retry/v3/retryadapter"

The predicate is borrowed and called synchronously without context checks or
direct panic recovery; separate executions may overlap or reenter. Consumers
own synchronization, bounded work and integration-resource lifetimes. No backend
dependency, transport, acknowledgement or background work is introduced.

FUNCTIONS

    Filesystem constructs a classifier using filesystem/backend evidence
    supplied by the caller. Mutation replay safety remains caller-owned.
